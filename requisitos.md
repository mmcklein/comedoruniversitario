# Requisitos del Sistema de Comedor Universitario UNAMBA

## Requisitos funcionales

| Codigo | Requisito |
|---|---|
| RF1 | Registrar y administrar a los usuarios del comedor. |
| RF2 | Gestionar las tarifas y tipos de racion disponibles. |
| RF3 | Publicar el menu diario y semanal. |
| RF4 | Permitir reservar una racion por turno y horario. |
| RF5 | Controlar el aforo disponible por turno. |
| RF6 | Calcular la tarifa segun la condicion de becario o no becario. |
| RF7 | Registrar pagos y emitir tickets con codigo QR. |
| RF8 | Validar la entrega de raciones. |
| RF9 | Administrar el inventario de insumos. |
| RF10 | Registrar asistencia y merma diaria. |
| RF11 | Generar reportes diarios de raciones, ingresos, asistencia y merma. |
| RF12 | Generar reportes y consultas historicas. |
| RF13 | Administrar usuarios y permisos del sistema. |

## Requisitos no funcionales

| Codigo | Requisito |
|---|---|
| RNF1 | El sistema debe contar con autenticacion segura. |
| RNF2 | Las operaciones deben responder en tiempo adecuado. |
| RNF3 | La informacion debe mantenerse confidencial e integrada. |
| RNF4 | La interfaz debe ser clara y facil de utilizar. |
| RNF5 | El sistema debe ser disponible durante los horarios de atencion. |
| RNF6 | Los datos deben tener respaldos periodicos. |
| RNF7 | El sistema debe permitir trazabilidad de registros y acciones. |
| RNF8 | El software debe ser compatible con los navegadores actuales. |
| RNF9 | El sistema debe facilitar su mantenimiento y evolucion. |
